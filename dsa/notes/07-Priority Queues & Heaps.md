# Heap

- Heap is a complete binary tree that satisfies the heap property.
- There are two type of heap, `Max-heap` and `Min-heap`.

1. Max Heap
    - The value of the parent node should be `greater than` or equal to either of its children.
2. Min Heap
    - The value of the parent node should be `less than` or equal to either of its children.
