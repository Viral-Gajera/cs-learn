# Bubble Sort:

Repeatedly sort two adjacent element if they are in wrong order.

# Selection sort:

Select the smallest element from the unsorted list and swap it with element at begining.

# Insertion sort:

Insert an element from unsorted array to its correct postion in sorted array.

Group 1

- Bubble Sort:
  Repeatedly sort two adjacent elements if they are in wrong order.

    ```java
    public static void bubbleSort(int[] arr) {
        int n = arr.length;

        for (int i = 0; i < n - 1; i++) {
            for (int j = 0; j < n - 1; j++) {
                if (arr[j + 1] < arr[j]) {
                    int temp = arr[j];
                    arr[j] = arr[j + 1];
                    arr[j + 1] = temp;
                }
            }
        }
    }
    ```

- Selection Sort:
  Select smallest element from unsorted array and swap it with front.

          ```java
          public static void selectionSort(int arr[]) {
              int n = arr.length;
              for (int i = 0; i < n - 1; i++) {
                  int min = i + 1;
                  for (int j = i + 1; j < n; j++) {
                      if (arr[j] < arr[min]) {
                          min = j;
                      }
                  }
                  // Caution 1:
                  if (arr[min] < arr[i]) {
                      arr[i] = arr[i] + arr[min];
                      arr[min] = arr[i] - arr[min];
                      arr[i] = arr[i] - arr[min];
                  }
              }
          }
          ```

- Insertion Sort:

    ```java
    public static void intertionSort(int[] arr) {
        int n = arr.length;
        for (int i = 1; i < n; i++) {
            int current = arr[i];
            int j = i - 1;
            while (j >= 0 && arr[j] > current) {
                arr[j + 1] = arr[j];
                j--;
            }
            arr[j + 1] = current;

        }
    }
    ```

- Merge Sort:

    ```java
    import java.util.Arrays;

    public class Merge {
        public static void divide(int[] arr, int low, int high) {
            if (low < high){
    		        int mid = (low + high) / 2;
    		        divide(arr, low, mid);
    		        divide(arr, mid + 1, high);
    		        merge(arr, low, mid, high);
            }
        }

        public static void merge(int[] arr, int low, int mid, int high) {
            int[] tmp = new int[high - low + 1];
            int i = low;
            int j = mid + 1;
            int k = 0;
            while (i <= mid && j <= high) {
                if (arr[i] < arr[j]) {
                    tmp[k] = arr[i];
                    i++;
                } else {
                    tmp[k] = arr[j];
                    j++;
                }
                k++;
            }
            while (i <= mid) {
                tmp[k] = arr[i];
                i++;
                k++;
            }
            while (j <= mid) {
                tmp[k] = arr[j];
                j++;
                k++;
            }

            k = 0;
            while (low <= high) {
                arr[low] = tmp[k];
                k++;
                low++;
            }
        }

        public static void mergeSort(int [] arr){
    		    divide(arr, 0, arr.length - 1);
        }

        public static void main(String[] args) {
            int arr[] = { 5, 4, 3, 2, 1 };
            mergeSort(arr);
            System.out.println(Arrays.toString(arr));
        }
    }

    // arr is call by reference so, no extra space counted, even in function call
    // tmp can go at max size of arr
    ```

- Quick Sort:
  Pick a pivot element & place it in it’s correct place in the sorted array.
  How to achive this? For the other elements then pivot, Smaller on the left and Larger on the right of pivot → This way the pivot will gets its correct postion
  Pivot can be any element in array (ie. first, last, median, etc)
