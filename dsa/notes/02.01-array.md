- Q. Print bar chart of given array.
    ```java
    For arr = {5,2,6,1,4,3,1,6,2,9}

                      *
                      *
                      *
        *         *   *
    *   *         *   *
    *   *   *     *   *
    *   *   * *   *   *
    * * *   * *   * * *
    * * * * * * * * * *
    5 2 6 1 4 3 1 6 2 9
    ```
    Approach:
    - Consider array element as height of building.
    - Find maximum height building - say 5.
    - Start with max level: 5th level, then 4th, … at last 1st level.
    - At 5th level, what will be there at 1 height building? → Air
    - At 5th level, what will be there at 5 height building? → Brecks
    ```java
    public static void printBarChart(int arr []) {

    	int max = arr[0];

    	for(int i=0; i<arr.length; i++) {
    		if(arr[i] > max) max = arr[i];
    	}

    	for(int i=max; i>0; i--) {
    		for(int j=0; j<arr.length; j++) {
    			if(arr[j]>=i) {
    				System.out.print("* ");
    			} else {
    				System.out.print("  ");
    			}
    		}
    		System.out.println();
    	}

    	for(int i=0; i<arr.length; i++) {
    		System.out.print(arr[i]+" ");
    	}
    }
    ```
- Q. Sum of two array
    ```java
    // Arrays can be of different size - Sum starts from last
    int arr1[] = {1, 9, 9};
    int arr2[] =    {8, 9};
    0 2 8 8

    // Also consider carry
    int arr1[] = {9, 9, 9};
    int arr2[] = {9, 9, 9};
    1 9 9 8
    ```
    ```java
    public static int [] addition(int arr1[], int arr2[]) {
    	int i = arr1.length-1;
    	int j = arr2.length-1;
    	int k = i>j?i:j;

    	int sum [] = new int[k+2];
    	int carry = 0;

    	k++;

    	while(k>0) {
    		int sumLocal = carry;

    		if(i >= 0) {
    			sumLocal += arr1[i];
    		}
    		if(j >= 0) {
    			sumLocal += arr2[j];
    		}

    		carry = sumLocal / 10;
    		sum[k] = sumLocal % 10;

    		i--;
    		j--;
    		k--;
    	}
    	sum[0] = carry;
    	return sum;
    }
    ```
