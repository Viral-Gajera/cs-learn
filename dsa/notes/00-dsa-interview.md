Q. What is Backtracking ?

- In Backtracking, We start with one possible option out of manay available options and cheack if it gives solution, otherwise we backtrack/undo/retrace and select some other option and try to solve problem.
- Backtracking is an improvement of the brute force approach.
- Backtracking is a form of recursion.
- Backtracking can be thought of as a selective tree/graph traversal method.

  

Q. Give example of popular recurrance relation ?

```LaTeX
Sum of first n natual number
T(n) = T(n-1) + 1
    
Factorial of number n
T(n) = T(n-1) + 1

Fibonacci series
T(n) = T(n-1) + T(n-2) + 1

Binary Search
T(n) = T(n/2) + 1

Merge Sort 
T(n) = 2T(n/2) + n

Quick Sort
T(n)=T(k)+T(n−k−1)+n)      // k represents the position of the pivot after the partitioning step

Tower of Hanoi
T(n) = 2T(n-1) + 1
```
