- Q. Count digit
    Q. Count digits in given number
    ```java
    public static int countDigit(long n){
        int count = 0;

        if(n==0) return 1;
        while(n!=0){
            count++;
            n/=10;
        }
        return count;
    }
    ```
    Time complexity: **O(log₁₀n + 1)**
    Space complexity: O(1)
    **Optimal solution:**
    - The logarithmic base 10 of a positive integer gives the number of digits in n.
    - We add 1 to the result to ensure that the count is correct even for numbers that are powers of 10.
    - So the count of digits can be calculated using log10 N + 1.
    - We cast the result to an integer to ensure that any fractional part is discarded giving the exact count of digits.
    ```jsx
    public static int countDigit(int n) {
        if (n == 0)
            return 0;
        return ((int) Math.log10(n)) + 1;
    }
    ```
    Time complexity: O(1)
    Space complexity O(1)

    ```java
        long output = 0;

            output = output*10 + n%10;
    ```

- Q. Prime number
    Q. Check the number is prime or not
    - Number which has exactly 2 factors 1 and number itself is called prime number.
    - 0 is not prime
    - 1 is not prime
    - 2 is prime
    Optimal solution:
    - We can optimize the algorithm by only iterating up to the square root of n when checking for factors.
    - **This is because if n has a factor greater than its square root, it must also have a factor smaller than its square root.**
    ```java

    public static boolean isPrime(int p) {
    	if(p<=1) return false;
    	if(p==2) return true;   // No need to check - think
    	for(int i=2; i<=Math.sqrt(p); i++) {
    		if(p%i==0) return false;
    	}
    	return true;
    }
    ```
    **Time Complexity: O(sqrt(N))**
    **Space Complexity : O(1)**
    Sieve of Eratosthenes algorithm for finding prime number

    ```java
    	int count = 0;
    	if(num==0) return 1;
    	while(num!=0) {
    		count++;
    		num/=10;
    	}
    	return count;
    }

    public static long rotate(int num, int n) {
    	int digits = countDigit(num);
    	n = n%digits;

    	if(n<0) n = digits + n;  // 1234,-1  --> 2341
    	                         // 1234, 3  --> 2341
    	                         // So left shift converted into right shift

    	int divisor = (int) Math.pow(10, n);
      int multiplier = (int) Math.pow(10, digits-n);

    	int remainder = num % divisor;
    	num = num/divisor;
    	num += remainder * multiplier;
    	return num;

    }
    ```

- Q. LCM & GCD
    Q. Find LCM (Least Common Multiple) and GCD (Greatest Common Divisor) of given two numbers.
    Brute force
    - LCM - Loop from max(a, b) to a\*b - 1, check i is divisible by both a and b.
    - GCD - Loop from min(a, b) to 2, check a and b divisible by i.
    Optimization
    - Use binary search
    Euclidean Algorithm for GCD:
    It operates on the principle that the GCD of two numbers remains the same even if the smaller number is subtracted (multiple time) from the larger number.
    ```java
    public static int gcd(int a, int b){
        while (a>0 && b>0) {
            if(a>b) a = a%b;
            else b = b%a;
        }
        return a==0?b:a;
    }
    ```
    Time complexity: $log_{\phi}(min(a,b))$
    Another method of finding LCM:
    - Relation between GCD and LCM **`gcd(a, b) * lcm(a, b) = a * b`.**
    ```java
    public static int lcm(int a, int b) {
    		return a*b / gcd(a,b);
    }
    ```

- Q. All factors of number
    Q. Print all the factors of a given Number
    - If d is a divisor of n, then n/d is also a divisor of n.
    - This property is symmetric about the square root of n.
    - By traversing just, the first half we can avoid redundant iteration
    !print-all-divisors-image1-fh-zLEup.png
    ```java
    public static ArrayList<Integer> findDivisors(int n) {

        ArrayList<Integer> divisors = new ArrayList<>();

        for (int i = 1; i <= Math.sqrt(n); ++i) {

            if (n % i == 0) {
                divisors.add(i);
                // Add the counterpart divisor, if it's different from i
                if (i != n / i) {
                    divisors.add(n / i);
                }
            }

        }
        return divisors;
    }
    ```
    Time complexity:  \*\*\*\*O(sqrt(N))
    Space Complexity: O(2\*sqrt(N))

- Q. Benjamin Bulbs
    Q. Benjamin Bulbs
    1. You are given n number of bulbs. They are all switched off initially. A weird fluctuation in voltage hits the circuit n times. In the 1st fluctuation all bulbs are toggled. in the 2nd fluctuation every 2nd bulb is toggled, in the 3rd fluctuation every 3rd bulb is toggled and so on. You've to find which bulbs will be switched on after n fluctuations.
    2. Take as input a number n. representing the number of bulbs.
    3. Print all the bulbs that will be on after the nth fluctuation in voltage.
    ```java
    public static void benjaminBulb(int n) {
        boolean arr[] = new boolean[n];
        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j += (i + 1)) {
                arr[j] = !arr[j];
            }
        }
        for (int i = 0; i < n; i++) {
            System.out.print(arr[i] + " ");
        }
    }
    ```
    Optimization:
    - For e.g. we are given with 20 bulbs
    - In first fluctuation all bulb toggled
    - In second fluctuation all multiple of 2 bulbs toggled.
    - In third fluctuation all multiple of 3 bulbs toggled.
    ![](attachment:9094ddbb-f104-4bf3-abb8-73e29f3e4289:nse-4719165347343966018-1000194136.jpg)
    Here all the **on bulbs** are perfect square. This all things depends on the number of factors of given number.
    - If the number has 4 factors, then it will toggle 4 time. Ex. 8 → 1, 2, 4, 8
    - If any number has even number of factors, then bulb remains off (on cancel by off).
    - If any number has odd number of factors, then bulb remains on.
    - All the perfect square has odd number of factors.
