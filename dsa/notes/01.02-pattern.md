For solving most of the pattern problem, we use nester loop

- Outer loop is for the lines, So iterate outer loop till number of lines `0 to n-1`
- Inner loop is for the column, Adjust inner loop according to outer loop.
- Add extra variable for `space`, `star`, `number` or `character` if required.

- Q. Print the following pattern (Pascal Triangle)
    This is based on the concept of permutation and combination.
    ```java
                01
              01  01
            01  02  01
          01  03  03  01
        01  04  06  04  01
      01  05  10  10  05  01
    01  06  15  20  15  06  01
    ```
    ```java

    public static void main(String[] args) {
      int n=7;

      for(int i=0; i<n; i++){
         for(int j=0; j<n-i-1; j++) System.out.print("  ");
         for(int j=0; j<=i; j++){
             System.out.printf("%02d  ",C(i,j));
         }
         System.out.println();
      }
    }

    public static int C(int n, int r){
        if (n<1 || r<1) return 1;

        int numerator = 1;
        int denominator = 1;

        while(r>0){
            numerator*=n;
            denominator*=r;
            n--;
            r--;
        }
        return numerator/denominator;

    }
    ```

    public static void main(String[] args) {
        int n = 5;

        int space = 2 * n - 2;

        for (int i = 1; i <= n; i++) {
            int counter = 1;
            while (counter <= i) {
                System.out.print(counter);
                counter++;
            }
            for (int j = 0; j < space; j++) {
                System.out.print(" ");
            }
            counter--;
            while (counter > 0) {
                System.out.print(counter);
                counter--;
            }
            space -= 2;
            System.out.println();
        }
    }
