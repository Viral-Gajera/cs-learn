 # Angualr

Q. What is Angular?

- [Angular was introduced](https://www.simplilearn.com/tutorials/angular-tutorial/what-is-angular) to create Single Page applications

  

Q. What is Angular CLI?

- Angular CLI is a command line interface tool that is used to initialize, develop, and maintain Angular applications.
- You will be using Angular CLI to speed up the development process of Angular applications.

  

Q. What is TypeScript?

- TypeScript is a superset of JavaScript.
- Enables developers to write object-oriented code in a statically-typed manner.

  

Q. What is compoent in angular?

- Components are the main building blocks for Angular applications.
- Each component consists of:
    - A CSS selector that defines how the component is used in a template (like `<app-root></app-root>`).
    - A TypeScript class that defines behaviour
    - An HTML template that declares what renders on the page
    - Optionally, CSS styles applied to the template
- Every Angular application has at least one component, the root component.

  

Q. What if `templeteUrl` and `templete` both specified in angular component ?

- `templateUrl` takes precedence over `template`.

  

Q. What is an Angular Module?

- An Angular Module, or NgModule, is a way to group together related code.
- Each Angular application has at least one Angular Module, the root module, which is conventionally named AppModule.

  

Q.What are Angular Directives

- Angular Directives are used to manipulate the DOM.
- They are a special kind of attribute that can be attached to elements or components.

  

Q. What is Angular Material?

- Angular Material is a UI component library that implements Material Design in Angular applications.
- It provides a variety of easy-to-use, customizable, and accessible UI components.

  

Q. What is Angular Ivy?

- Angular Ivy is the latest rendering engine for Angular.
- It aims to make the framework smaller, simpler, and faster to compile.
