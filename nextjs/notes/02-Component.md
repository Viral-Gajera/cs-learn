# Client Component Vs Server Component

- By default, All the component in next.js are server components.
- Server component executed/rendered on server side.
- Client component executed/rendered on client side (i.e. Brower).

## Server Component

- Advantage of server component, Less client side javascript, great for the SEO.
- In server component we can directly execute server side code like, SQL query.
- Hook are not available to server component.
- Event Handlers are not available to server component.

## Client Component

- To make server component to client component, add `"user client";` directive to top of the file.

# Head

- Next.js expose a built-in component for appending elements to the `head` of the page:
- Example:

```jsx
import Head from 'next/head';

function IndexPage() {
	return (
		<div>
			<Head>
				<title>My page title</title>
				<meta property="og:title" content="My page title" key="title">
			</Head>
			
			<p>Hello world!</p>
		</div>
	)
}

export default IndexPage
```

- `title`, `meta` or any other elements (e.g. `script`) need to be contained as **direct** children of the `Head` element, or wrapped into maximum one level of `<React.Fragment>` or arrays otherwise the tags won't be correctly picked up on client-side navigations.

- OR

- Dynamic metadata depends on dynamic information, such as the current route parameters, external data, or `metadata` in parent segments, can be set by exporting a `generateMetadata` function that returns a [`Metadata`](https://nextjs.org/docs/app/api-reference/functions/generate-metadata#metadata-fields) [object](https://nextjs.org/docs/app/api-reference/functions/generate-metadata#metadata-fields).
- Example:

```JavaScript
export async function generateMetadata({ params, searchParams }, parent) {
  // read route params
  const id = params.id

  // fetch data
  const product = await fetch(`https://.../${id}`).then((res) => res.json())

  // optionally access and extend (rather than replace) parent metadata
  const previousImages = (await parent).openGraph?.images || []

  return {
	title: product.title,
	openGraph: {
	  images: ['/some-specific-page-image.jpg', ...previousImages],
	},
  }
}

export default function Page({ params, searchParams }) {}
```

# Script

- The Script component, next/script, is a built-in component in Next.js that allows you to add third-party scripts to your application.
- It is an extension of the HTML `<script>` element and provides more control over when and how scripts are loaded.
- Syntax:

```jsx
import Script from 'next/script'

export default function Dashboard() {
	return (
		<>
			<Script src="https://example.com/script.js" />
		</>
	)
}
```


**Props :**

| Prop       | Example                           | Type     | Required                              | Description                                                   |
| ---------- | --------------------------------- | -------- | ------------------------------------- | ------------------------------------------------------------- |
| `src`      | `src="http://example.com/script"` | String   | Required unless inline script is used |                                                               |
| `strategy` | `strategy="lazyOnload"`           | String   | -                                     | beforeInteractive \| afterInteractive \| lazyOnload \| worker |
| `onLoad`   | `onLoad={onLoadFunc}`             | Function | -                                     |                                                               |
| `onReady`  | `onReady={onReadyFunc}`           | Function | -                                     |                                                               |
| `onError`  | `onError={onErrorFunc}`           | Function | -                                     |                                                               |

# Suspense (React)

- It is used to display the fallback content while the component is loading.
- Example:

```jsx
import { Suspense } from 'react';
import { PostFeed, Weather } from './Components';

export default function Posts() {
  return (
	<section>
		<Suspense fallback={<p>Loading feed...</p>}>
			<PostFeed />
		</Suspense>
		<Suspense fallback={<p>Loading weather...</p>}>
			<Weather />
		</Suspense>
	</section>
  )
}
```
