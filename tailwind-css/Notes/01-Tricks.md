```jsx
shadow-purple-500/50
- specifies the color using 'purple'
- specifies opacity using '/50' 
- range is between 0 to 100

accent-purple-500
- change color of checkbox

bg-[#427651]
- specifies custom value using square brackets

font-custom
- to setup custom fonts
- also we need to setup tailwind.config file

appearance-none
- removes arrow from <select>
```



```
select-none
- stop selecting texts
max-sm | max-md | max-lg ...
- inverted break points

md:max-xl:flex
- breakpoint range
```
