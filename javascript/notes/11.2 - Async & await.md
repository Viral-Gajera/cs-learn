## Async and Await

- Async and Await make promises easier to read/write.
- `Async` makes a function return a Promise. ( works asynchronous)
- `Await` makes a function wait for a Promise. ( work synchronously inside async function )

### Async :

- The keyword `async` before a function makes the function return a promise when it called.
- if async function returns a value then it is same as, `return Promise.resolve("resolve value");`
- so, `async` ensures that the function returns a promise, and **wraps non-promises value into promise**.
- async function may contains one or many `await` statement.

Syntax:

```JavaScript
async function funcName() {
	// function body;
	// return value;
	// return Promise.resolve(resolve value);
}
```

Example:

```JavaScript
async function Func(){
    return new Promise( function(resolved, rejected){
        let x = Math.random();

        if( x >= 0.5 ){
            resolved(`Promise resolved with value ` + x.toFixed(2));
        }
        else{
            rejected(`Promise rejected with value ` + x.toFixed(2));
        }
    } )

}

Func()
    .then( console.log )
    .catch( console.log );
```

### Await :

- The await keyword can only be used inside an async function. (If we try to use await in a non-async function, there would be a syntax error).
- It only makes the async block wait.
- The keyword `await before a promise object`, wait for a promise settles.
- **await** returns `resolve value` or `error` in case of rejection reason of promise.

Syntax:

```JavaScript
// works only inside async functions
let value = await promise;
```

Example:

```JavaScript
let p = new Promise( function(resolved, rejected){
    let x = Math.random();

    if( x >= 0.5 ){
        resolved(`Promise resolved with value ` + x.toFixed(2));
    }
    else{
        rejected(`Promise rejected with value ` + x.toFixed(2));
    }

} )


async function Func(){
    try{
        let value = await p;
        console.log(value);
    }
    catch(err){
        console.log(err);
    }
}

Func();
```
