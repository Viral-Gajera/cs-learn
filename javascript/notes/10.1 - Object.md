# Creating object

### 1. using 'Object' constrtor:

- The Object constructor creates an object wrapper for the given value.
    
    ```Plain
    let car = new Object();
    car.name = 'Ford';
    car['model'] = 'Mustang';
    car.year = 1969;
    ```
    

### 2. using object literal

- An object literal is typically used to create a single object whereas a constructor is useful for creating multiple objects:
    
    ```Plain
    let person = {
    
        firstName : 'viral',
        lastName : 'gajera'
    
        fullName : fucntion() {
            return this.firstName + " " + this.lastName;
        }
    
    }
    ```
    

### 3. using Object.create()

- The `Object.create(proto, propertiesObject)` method creates a new object, using an existing object as the prototype of the newly created object.
    
    ```Plain
    const person = {
      isHuman: false,
      printIntroduction: function() {
        console.log(`My name is ${this.name}. Am I human? ${this.isHuman}`);
      }
    };
    
    const me = Object.create(person);
    
    me.name = 'Matthew';     // "name" is a property set on "me", but not on "person"
    me.isHuman = true;         // inherited properties can be overwritten
    
    me.printIntroduction();
    // expected output: "My name is Matthew. Am I human? true"
    ```
    

### 4. using constructor fucntion:

- A constructor is a special function that creates and initializes an object.
- Any function can be use as 'constructor function'.
- JavaScript also has buit-in construor like `Object()`, `String()`, `Number()`, `Boolean()`...
- `this` keyword refers to the newly created object inside constuctor.
- Constructor function is simple function but it called with `new` operator.

When fucntion called with 'new' keyword.

- New empty obj `{}` created.
- Function is called, newly created obj assigned to 'this'.
- New obj `{}` linked to prototype.
- Function automatically return 'newly created obj {}'.

you can create an object using construtor with these two steps:

- Define the object type by writing a constructor function.
- Create an instance of the object with new.

once constructor function is defined, we can create any number of object using it.

Example :

```Plain
function Car(make, model, year) {
  this.make = make;
  this.model = model;
  this.year = year;
}

let myCar = new Car('ford', 'mustang', 1969);

// arrow function not work as constructor function.
```

### Method :

- A method is a function associated with an object.
- Methods cannot be constructors! They will throw a `TypeError` if you try to instantiate them.
- Methods are defined the way normal functions are defined, except that they have to be assigned as the property of an object.

Syntax:

```Plain
// 1. defining methods
let obj = {
    func : function( argList ){
        /* method body */
    }

    /* enhanced object literal */
    func( argList ){
        /* method body */
    }

}

// 2. defining methods
let obj = new anyConstructor();
obj.func = function ( argList ){
    /* method body */
}

// calling methods
obj.fucn( arg... );
obj.['fucn']( arg... );
```

### The `this` keyword :

- JavaScript has a special keyword, `this`, that we can use within a method to refer to the 'current object'.
- `this` keyword is reference variable points to object.
    - in a method, 'this' referes to current object. (same in strict mode)
    - alone, 'this' referes to the global object. (same in strict mode)
    - in a function, 'this' referes to the gloabal obejct ('undefined' in strict mode)
    - in an event, 'this' refers to the 'element' that received the event.

### Getters and Setters :

- In JavaScript, there are two kinds of object properties:
    - Data properties
    - Accessor properties

Getter and Setter are the data accessor property.

- A getter is a method that gets the value of a specific property.
- A setter is a method that sets the value of a specific property.
- When defining getters and setters using object literal, you need to do is to prefix a getter method with `get` and a setter method with `set`.
- The getter method **must not expect a parameter**, while the setter method **expects exactly one parameter**.
- getter and setter both method can have same name

Syntax :

```Plain
get propName(){
    //method body
}

set propName(value){
    //method body
}
```

Example:

```Plain
let obj = {
    firstName : 'viral',
    lastName : 'gajera',

    get getFullName(){
        return `${this.firstName} ${this.lastName}`;
    } ,

    set setFullName ( name="" ){
        [this.firstName, this.lastName] = name.split(' ');
    }

}

console.log(obj.getFullName);
obj.setFullName = "Elon musk"
console.log(obj.getFullName);
```

Getters and setters can also be added to an object at any time after creation using the Object.defineProperties() method.

### Deleting Object Property :

- The `delete` keyword used to delete a property from an object:
- The `delete` keyword deletes both the value of the property and the property itself.

Example:

```Plain
const person = {
  firstName: "John",
  lastName: "Doe",
  age: 50,
  eyeColor: "blue"
};

delete person.age;
delete person["age"];
```

### Property Attributes :

- All the object properties have a name and they also have a value, in addition it also has attributes like :
    
    writable, enumerable and configurable.
    
- The value is one of the property's attributes.

```Plain
Object.getOwnPropertyDescriptor( obj, 'prop' );
this method returns an 'object' describing the configuration of a 'specific property' on a given object.

Object.getOwnPropertyDescriptors( obj );
this method returns all own property descriptors of a given object.

Object.defineProperty(obj, 'prop', descriptorObject);
this static method defines a new property directly on an object, or modifies an existing property on an object, and returns the object.
```

Example :

```Plain
let Person = {
    firstName : 'viral',
    lastName : 'gajera',
    age : 19
}

console.log(
    Object.getOwnPropertyDescriptor( Person, 'age' )
);

Object.defineProperty(Person,'age', { writable: false, enumerable: true, configurable: false})

console.log(
    Object.getOwnPropertyDescriptor( Person, 'age' )
);
```

### Comparing Objects :

- Objects are a reference type. Two distinct objects are never equal, even if they have the same properties.
- Only comparing the same object reference with itself yields true.

Example :

```Plain
// Two variables, two distinct objects with the same properties
const fruit = {name: 'apple'};
const fruitbear = {name: 'apple'};

fruit == fruitbear; // return false
fruit === fruitbear; // return false
```

Example :

```Plain
// Two variables, a single object
const fruit = {name: 'apple'};
const fruitbear = fruit;  // Assign fruit object reference to fruitbear

// Here fruit and fruitbear are pointing to same object
fruit == fruitbear; // return true
fruit === fruitbear; // return true
```
