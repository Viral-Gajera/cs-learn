## Promise object :

- A Promise is an object, representing the completion or failure of an asynchronous operation.
- Promise executes certain code if, it is resolved, or executes other code, if it is not resolved (rejected).

Constructor :

```JavaScript
new Promise(Executor);
```

Static methods :

```Plain
Promise.all(iterable)
Promise.any(iterable)
Promise.race(iterable)
Promise.allSettled(iterable)

Promise.reject(reason)
Promise.resolve(value)
```

Instance methods :

```Plain
Promise.prototype.then()
Promise.prototype.catch()
Promise.prototype.finally()
```

### promise characteristics:

- promise can be chainable.
- A promise has three stats :
    
    |States|Description|
    |---|---|
    |pending|initial state, neither fulfilled nor rejected|
    |fulfilled|meaning that the operation was completed successfully (settled)|
    |rejected|meaning that the operation failed (settled)|
    

A pending promise can either be fulfilled with a value or rejected with a reason (error).

### 1. understanding constructor :

syntax:

```JavaScript
new Promise(Executor);
```

Executor's signature is expected to be:

```JavaScript
new Promise(
	function (resolveFunc, rejectionFunc) {		<--- Executor
		resolveFunc(value);						<--- call if resolved
		rejectionFunc(reason);					<--- call if rejected
	}
);
```

- Executor is a function to be executed by the constructor(automatically), during the process of constructing the new Promise object.
- Executor function takes two functions as parameters.
- The first functions called when the asynchronous task completes successfully, it accept one parameter 'value' and returns the 'results' of the task as a 'value'.
- The second function called when the task fails, it accept one parameter as 'reason' and returns the 'reason' for failure, which is typically an error object.
- Once a Promise is settled, the respective handler function onFulfilled or onRejected of .then() method, will be called asynchronously
- The executor return value is ignored.
- The Promise constructor returns new promise object.
- If an error is thrown in the executor, the promise is rejected.

Example:

```JavaScript
let x = Math.random();

let p = new Promise(
    function(resolved, rejected){
        if(x > 0.5){
            resolved('Promise resolved');
        }
        else{
            rejected('Promise rejected');
        }
    }
);

p.then( function(value){
    console.log(value);
} ).catch( function(reason){
    console.log(reason);
} );

or

p.then( function (value) {
    console.log(value);
}, function (reason) {
    console.log(reason);
});
```

### 2. undersanding .then() method

```JavaScript
Promise.prototype.then(onFulfilled, [onRejected] )
```

The then() method returns a promise instance.

Parameter:

- It takes `two handler functions` for the success and failure cases of the Promise.
- onFulfilled(value) : Function called if the Promise is fulfilled (on resolveFunc(value) called). This function has one argument, the `fulfillment value` (which is passed form resolveFunc(value)).
- onRejected(reason) : Function called if the Promise is rejected (on rejectionFunc(reason) called). This function has one argument, the `rejection reason` (which is passed from rejectionFunc(reason)).

### 3. undersanding .catch() method

```Plain
Promise.prototype.catch(onRejected)
```

The catch() method returns a Promise instance.

it deals with rejected cases only. calling `obj.catch(onRejected)` internally calls `obj.then(undefined, onRejected)`.

Parameters:

- onRejected(reason) : A Function called when the Promise is rejected. This function has one argument, the rejection reason.

### 4. understanding .finally() method;

```Plain
Promise.prototype.finally(onFinally)
```

- onFinally Function always executed whether the promise is fulfilled or rejected.
- Returns an equivalent Promise with its finally handler set to the specified function.

  

# PROMISE CHAINING

There are five basic rules to understand and follow to get a firm grip on the promise chain.

### Rule # 1

Every promise gives you a .then() handler method. Every rejected promise provides you a .catch() handler.

### Rule # 2

You can do mainly three valuable things from the .then() method. You can return another promise(for async operation). You can return any other value from a synchronous operation. Lastly, you can throw an error.

|   |   |
|---|---|
|Return value|then() method return value|
|promise|new promise with resolve value or rejection reason.|
|value|promise with resolve value as 'value'.|
|throws Error|promise with rejection value as thrown value or value passed to constructor.|

### Rule # 3

You can rethrow from the .catch() handler to handle the error later. In this case, the control will go to the next closest .catch() handler.

### Rule # 4

Unlike then() and catch(), the finally() handler doesn't process the result value or error. It just passes the result as is to the next handler.

### Rule # 5

Calling the .then() handler method multiple times on a single promise is NOT chaining.
