## RegExp Object :

- The RegExp object is used for matching text with a pattern.
- Creating regular expression with constructor function:
    
    ```Plain
    let re = new RegExp('pattern', 'flags',...);
    ```
    
- Example :
    
    ```Plain
    let re = new RegExp('ab+c', 'i');
    let re = new RegExp(/ab+c/, 'i');
    ```

RegExp()
// Creates a new RegExp object.
