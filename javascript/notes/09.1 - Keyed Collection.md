## Map and set:

- Maps are simliar to objects in that they can map a key to a value, and sets are similar to arrays except that duplicate are not allowed.
- Map and Set objects contain elements which are iterable in the order of insertion.

  

# Maps object :

- The Map object holds key-value pairs and remembers the original insertion order of the keys(unlike object).
- Any value (objects, primitive values, NaN...) may be used as either a key or a value.

### Map vs Object :

- The keys of an Object are Strings or Symbols, where the key of Map can be of any value (primitive or object).
- You can get the size of a Map easily, while you have to manually keep track of size for an Object.
- Map maintains insertion order of the elements where as object does not.
- Syntax :
    
    ```Plain
    // Creating map:
    new map([iterables]);
    
    // optional argument, iterables is An Array or other iterable object
    // whose elements are key-value pairs
    
    // accessing element:
    mapInstance.get(key);
    
    // add/updating element:
    mapInstance.set(key,value)
    ```
    
- Example :
    
    ```Plain
    // pass an array of arrays to the constuctor
    
    let myMap = new Map([
         [1, 'one'],
         [2, 'two'],
         [3, 'three'],
    ]);
    ```

### Map properties :

- Setting the properties of Map works same as object, and can cause considerable confusion.
- Syntax:
    
    ```Plain
    map['propery']				// accessing property
    map['propery'] = value;		// setting property
    ```
    
      
    
- Example :
    
    ```Plain
    let myMap = new Map();
    
    myMap['firstName'] = 'viral';	//it is not map entry
    myMap['firstName']
    ```

### Iterating Map with for..of :

```Plain
const myMap = new Map()
myMap.set(0, 'zero')
myMap.set(1, 'one')

for (const [key, value] of myMap) {
  console.log(key + ' = ' + value)
}
// 0 = zero
// 1 = one

for (const key of myMap.keys()) {
  console.log(key)
}
// 0
// 1

for (const value of myMap.values()) {
  console.log(value)
}
// zero
// one

for (const [key, value] of myMap.entries()) {
  console.log(key + ' = ' + value)
}
// 0 = zero
// 1 = one
```

### Iterating Map with forEach()

```Plain
myMap.forEach(function(value, key) {
  console.log(key + ' = ' + value)
})
// 0 = zero
// 1 = one
```

  

# WeakMap object :

- A WeakMap is a collection of key/value pairs whose keys must be objects, with values of any arbitrary JavaScript type, and which does not create strong references to its keys.
- Object's presence as a key in a WeakMap does not prevent the object from being garbage collected.
- Once an object used as a key has been collected, its corresponding values in any WeakMap become candidates for garbage collection as well.
- Characteristics :
    - Weak map key must be an object, value can be of any type.
    - Weak map cannot be iterated or cleared
    - Keys in weakmap can be garbage colleacted
- Syntax :
    
    ```Plain
    create:
    new WeakMap([iterable]);
    
    access element:
    WmInstance.get(key);
    
    add element:
    WmInstance.set(key, value)
    ```
    
- Example :
    
    ```Plain
    let jon = {name : 'Jon'};
    let m = new Map();
    m.set(jon, 'Any')
    jon = null;
    console.log(m); // Map { {} => 'Any' }
    
    let jonas = { name: "jonas" };
    let wm = new WeakMap();
    wm.set(jonas,'Any');
    jonas = null;
    console.log(wm); // WeakMap { No Entries }
    ```

```Plain
	console.log(item)
```
