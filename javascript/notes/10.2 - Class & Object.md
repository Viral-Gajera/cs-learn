## Object Oriented Programming

## Four OOPs concept :

### Abstraction :

- hiding the implementation details and only shows the functionality to the user.
- OOP language use abstract classes and interface to achieve data abstaction.

### Encapsulation :

- Wrapping up data and methods together into a single unit called class.
- Hides data for the purpose of data protection.
- Encapsulation can achive by making the data member private and accessing them through public method.

### Inheritance :

- Deriving new class form existing class is called inheritance.
- It provides data reusablity.
- The class whose members are inherited is called the 'base class', and the class that inherits those members is called the 'derived class'.

## Classes and Objects :

- Introduced in ES6
- Classes are a blueprint/template/map for creating objects.
- ECMAScript 2015 introduced, new keywords include class, constructor, static, extends, and super.
- Class characteristics :
    - Classes are not hoisted.
    - A class can't be redefined.
    - Classes are first-class citizes.
    - Classes(body of class) are always executed in strict mode.
- Class can be created in two ways: `class expressions` and `class declarations`
- `class` keyword is used to create class.

### Class Declaration :

- To declare a class, you use the class keyword with the name of the class.
- Syntax:
    
    ```Plain
    // class declaration
    class class_name{
    	constructor(){
      		// constructor body
      	}
    }
    
    //creating object
    let obj = new class_name(argList);
    ```
    
- Example :
    
    ```Plain
    class Rectangle {
      constructor(height, width) {
        this.height = height;
        this.width = width;
      }
    }
    
    let rect1 = new Rectangle(10,15);
    ```
    

### Class Expression :

- Class expressions can be named or unnamed. The name given to a named class expression is local to the class's body. However, it can be accessed via the "name" property.
- Syntax :
    
    ```Plain
    let class_name = class [class_name - optional]{
    	//class body
    }
    ```
    
- Example :
    
    ```Plain
    let Rectangle = class Rect {
      constructor(height, width) {
        this.height = height;
        this.width = width;
      }
    };
    console.log(Rectangle.name);
    // output: "Rect"
    // output: "Rectangle" if unnamed
    ```
    

Creating Instance of class :

- Creating object from class
- The 'new' operator used to create an instance of a user-defined object type or of one of the built-in object types that has a constructor function.
- Parentheses can be omitted if the constructor takes no arguments.
- Syntax :
    
    ```Plain
    let obj = new MyClass(args...);
    ```
    

## Class Body :

- The body of a class is the part that is in curly brackets `{}`. This is where you define class members, such as methods or constructor.
- The body of a class always executes in strict mode.

### Constructor :

- The constructor method is a special method for creating and initializing an object created with a class.
- There can only be one special method with the name `constructor` in a class.
- A constructor can use the `super` keyword to call the constructor of the super class.
- `constructor()` function is automatically called when the object is instantiated.

### Instance Property :

- Instance properties must be defined inside of class methods.
- Example :
    
    ```Plain
    class Rectangle {
    	constructor(height, width) {
        	this.height = height;
        	this.width = width;
    	}
    }
    ```

### Field Declaration :

### Public field declarations :

- JavaScript public field declaration syntax is as follows :
    
    ```Plain
    class ClassName
    {
    	variable;  // without let, var or const
    
    	methodName(){
    		//body
    	}
    }
    
    
    Example:
    
    class Rectangle {
      height = 0;
      width;
      constructor(height, width) {
        this.height = height;
        this.width = width;
      }
    }
    ```
    

### Private field declarations :

- JavaScript private field declaration syntax is as follows :
    
    ```Plain
    Class ClassName
    {
    	\#variable;  (without let, var or const)
    	(hash # prefix)
    
    	\#funcName(){
    		//function body
    	}
    }
    ```
    
- private field can only be read or within the class body. It gives error, if reference private fields from outside of the class.
- Note: Private fields can only be declared up-front in a field declaration.
- Example :
    
    ```Plain
    class Rectangle {
      \#height = 0;
      \#width;
      constructor(height, width) {
        this.\#height = height;
        this.\#width = width;
      }
    }
    
    let rect = new Rectangle(100,500);
    
    console.log(rect.height);	//undefined
    console.log(rect.\#height);	//error
    ```
    

### Static methods and properties :

- The `static` keyword defines a static method or property for a class.
- Static members can called without instantiating their class and cannot be called through a class instance.
- Example :
    
    ```Plain
    class Point {
        constructor(x, y) {
          this.x = x;
          this.y = y;
        }
    
      static displayName = "Point";
      /* equivalent to Point.displayName = "Point" */
    
      static distance(a, b) {
        const dx = a.x - b.x;
        const dy = a.y - b.y;
    
        return Math.hypot(dx, dy);
    
      }
      /* equivalent to Point.distance = function(){} */
    }
    
    const p1 = new Point(5, 5);
    const p2 = new Point(10, 10);
    
    // calling static method
    console.log(Point.displayName);      // "Point"
    console.log(Point.distance(p1, p2)); // 7.0710678118654755s
    
    p1.displayName; // undefined
    p1.distance;    // undefined
    p2.displayName; // undefined
    p2.distance;    // undefined
    ```
    

### Static initialization block:

- Class static initialization blocks are a special feature of a class that enable <u>more flexible initialization of static properties</u> than can be achieved using per-field initialization.
- The 'this' inside a static block refers to the constructor object/function of the class.
- Multiple static blocks can be declared.
- Syntax :
    
    ```Plain
    static { /* ... */ }
    ```
    
- Example :
    
    ```Plain
    class StaticBlock
    {
    	static staticProperty1 = 'Property 1';
    
      	static
      	{
        	console.log(this);  	// StaticBlock
        	this.staticProperty2 = 'Property 2';
      	}
    }
    
    console.log(StaticBlock.staticProperty1);
    // output: "Property 1"
    console.log(StaticBlock.staticProperty2);
    // output: "Property 2
    ```
    

Note :

- When a static or prototype method is called "without a value for this", such as by assigning the method to a variable and then calling it, the `this` value will be undefined inside the method.
- This behaviour will be the same even if the "use strict" directive isn't present (because class body always executes in 'strict mode').
