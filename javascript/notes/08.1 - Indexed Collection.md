# Indexed collections:

- Indexed collections introduces collections of data which are ordered by an index value.
- This includes arrays and typed-array.

# Array :

- An array is an ordered list of values that you refer with a **name and an index**.
- Array element can be primitive values or object, function, another array, expression etc,...
- The array's length property is set to the number of elements.
- index starts with 0 and goes upto length-1.
- You can also assign the value to the length property.
  
    Writing a value that is shorter than the number of stored items, truncates the array. Writing 0 empties it entirely.
    

Syntax:

```Plain
// Create : (The following statements create equivalent arrays )

let arr = new Array(E0, E1, ..., EN);
let arr = Array(E0, E1, ..., EN);
let arr = [E0, E1, ..., EN];		(array literal)

accessing element :
arr[index]

add/update element :
arr[index] = value;
```

Example:

```Plain
let arr = ['one', 'two', 'three']
arr[2]          // three
arr['length']   // 3	(property accessor)
```

Populating an array:

You can populate an array by assigning values to its elements. For example :

```Plain
let person = [];
emp[0] = 'Elon musk';
emp[1] = 'Jeff Bezos';
emp[2] = 'Bill Gates';
```

If you supply a non-integer value to the array operator in the code below, a `property` will be created in the object representing the array, instead of an array element.

```Plain
person[3.4] = 'Viral Gajera'
console.log(person.length)                 // 3
console.log(person.hasOwnProperty(3.4))    // true
```

### Array object :

- The Array object, enables storing a collection of multiple items under a single variable name, and has members for performing common array operations.
- Array objects core characteristics:
- JavaScript arrays are resizable and can contain a mix of different data types.
- JavaScript arrays are not associative arrays ( array elements cannot be accessed using strings as indexes, but must be accessed using integers as indexes.)
- JavaScript array index are zero based.
- JavaScript array-copy operations create shallow copies.

### Array.prototype.sort()

- description :
    - The sort() method sorts the elements of an array. The default sort order is ascending, built upon converting the elements into strings, then comparing their sequences of UTF-16 code units values.
- Return :
    - it returns the sorted array ( also mutates original array ).
    - All undefined elements are sorted to the end of the array.
- Syntax :
  
    ```Plain
    sort( function compareFn(a, b) { /* ... */ });
    Array.prototype.sort( (a, b) => { /* ... */ } );
    ```
    
    - compareFn:
      
        - Specifies a function that defines the sort order.
        - `a`  
            The first element for comparison.  
            
        - `b`  
            The second element for comparison.  
            
            |   |   |
            |---|---|
            |compareFunction(a, b) return value|sort order|
            |> 0|sort `a` after `b`|
            |< 0|sort `a` before `b`|
            |== 0|keeep origianl order of a and b|
            
            To compare numbers instead of strings, the compare function can subtract b from a.
            
        
        Example :
        
        The following function will sort the array in ascending order.
        
        ```Plain
        function compareNumbers(a, b) {
            return a - b;
          }
        
        let x = [25,20,15,10,5];
        
        x.sort(compareNumbers)
        
        console.log(x);		// [5, 10, 15, 20, 25]
        ```

### Array.prototype.filter()

`filter((element, index, array) => {/* ... */} )`

- returns newly created array.
- this method creates a new array filled with elements that pass a test provided by a function.
  
    description :
    
    - The filter() method creates a new array filled with elements that pass a test provided by a function.
    - if return value of callback function is true, then element added to newArray, discarded otherwise.
    - The filter() method does not execute the function for empty elements.
    
    return :
    
    - newly created array
    - The filter() method does not change the original array.
    
    syntax :
    
    ```Plain
    filter((element, index, array) => { /* ... */ } )
    filter(function(element, index, array) { /* ... */ }, thisArg)
    ```
    
    callback function test each element of the array. if condition becomes true, then element pushed to newArray.
    
    Example :
    
    ```Plain
    let arr = [200,400,-1300, 150, -200,1000,600];
    arr.filter( e => e>200 )  //[400, 1000, 600]
    ```

`findIndex((element, index, array) => {/* ... */} )`

### Array.prototype.flat()

`flat(depth)`

### Array.prototype.flatMap()

`flatMap((currentValue, index, array) => { /* ... */ })`

### Array.prototype.fill()

`fill(value, start, end)`

- This method changes all elements in an array to a static value, from a start index (default 0) to an end index (default array.length). It returns the modified array.
