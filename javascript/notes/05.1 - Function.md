## Basic :

- A function is block/group of statement that together perform a specific task.
- Function takes in input as parameter, process it, and then outputs the result.

### Function declaration :

- Function declaration consists of the `function` keyword followed by
    - The name of function.
    - A list of parameters that function have, enclosed in parantheses and seperated by commas.
    - Function body enclosed in curly bracket ( `{...}` ).
- Syntax :
    
    ```Plain
    function func_name (param, param, ...)
    {
        //statement;
    }
    ```
    
    Example :
    

```Plain
function add(a, b)
{
    let sum = a+b;
    rerturn sum;
}
```

- The return statement returns specified value or `undefine` if there are no return statement.
- The parameters of a function call are the function's arguments. Arguments may be passed by value (in the case of primitive values) or by reference (in the case of objects).
- Funciton declaration hoisted to top of the scope.

Calling function :

- To call a function, you simply needs to pass the required parameters along with the function name, and if the function return a value then you can store the return value.
    
    Syntax :
    
    ```Plain
    funcName(param, param,...);
    ```
    
    Example :
    
    ```Plain
    add(11, 13);
    ```
    

Calling vs Referencing :

- When you follow a function identifier with parantheses, javaScript known that you're calling it.
- When you don't provide the parantheses, you're simply referring to the function just like any other value, and it's not invoked.
    
    ```Plain
    getGreeting();        // 'hello world';
    getGreeting;        // function getGreeting()
    ```
    

Function Argument :

- In many language, a function's signature includes its argument, but javaScript don't.
- When you have function named `f`, you can call it with 0 or 1 or 10 arguments and you're calling the same fucntion.
- You can call any function with any number of arguments. if you fail to provide arguments they will implicitly receive the value `undefine`.
- JavaScript Does not support Function Overloading.
    
    Example :
    
    ```Plain
    function foo(arg1)
    {
        console.log(arg1);
    }
    
    function foo(arg1, arg2)
    {
        console.log(arg1, arg2);
    }
    
    /* The above function will be overwritten by the function below, and the below function will be executed for any number and any type of arguments */
    
    // Driver code

    ```
    
    Output :
    
    ```Plain
    Geeks undefined
    ```
    
    - we can also have destructured arguments.
    - [destructuring object/array and spread operator for rest parameter]

Default argument :

- Normally, when values for argument aren't provided, they get a value of `undefine`. default values allow you to sepecify some other default value.
    
    ```Plain
    function f(a, b='default', c=3){
        return `${a} : ${b} : ${c}`
    }
    
    f(5,6,7);        // '5 : 6 : 7'
    f(5,6);            // '5 : 6 : 3'
    f(5);            // '5 : default : 3'
    f();            // 'undefine : define : 3'
    ```
    

### Function expression (anonymous function) :

- The main difference between a function expression and function declaration is the `function name`. which can be omitted in function expression to create anonymous funcution.
- Syntax :
    
    ```Plain
    let funcName = function (param, param,... )
    {
        //statements;
    }
    ```
    
- Example :
    
    ```Plain
    const add = function (a, b)
    {
        return a+b;
    }
    
    add(11, 13);
    ```
    

### Arrow function :

- An arrow function expression is a compact alternative of tradition function expression but, is limited and can't be used in all situation.
- An arrow function expression has a shorter syntax and lexically binds its this value
- Syntax :
    
    ```Plain
    // one parameter, with simple expression, return is not needed.
    param => expression;
    
    // multiple parameter required parantheses. with simple expression return is not needed.
    (param1,..., paramN) => expression;
    
    // multiple statemnet required body braces and 'return' statement.
    (param1, ..., paramN) => {
        statement;
    }
    ```
    
- Example :
    
    ```Plain
    let add;
    
    add = function (a,b){
        return a+b;
    }
    
    add = (a, b) => {
        return a+b;
    }
    
    add = (a, b) => a+b;
    
    add(13, 17);    //calling function.
    ```

### The 'this' keyword :

- `this` keyword is reference variable points to object.
    - In an object method, this refers to the object. [ same in strict mode ]
    - Alone, this refers to the global object. [ same in strict mode ]
    - In a function, this refers to the global object. [ 'undefined' in strict mode ]
    - In an event handle function, this refers to the `element` in which event occurred.
- normally, the this keyword related to function that are properties of object.
- when methods are called the this keyword takes value of specificed object on which it was called on.
    
    Example :
    
    ```Plain
    let obj = {
        a : 10,
        b : 20,
        func : function(){
            console.log(this);
            console.log(this.a);
            console.log(this.b);
            // arrow function does not get it own 'this' var, it uses lexical 'this'.
        }
    };
    
    obj.func();
    ```
    
    Output :
    
    ```Plain
    {a: 10, b: 20, func: ƒ}
    10
    20
    ```
    
    it's importent to understand that 'this' is bound according to how the function is called, not where the function is declared.
    
    Example :
    
    ```Plain
    let obj = {
        a : 10,
        b : 20,
        func : function(){
            console.log(this);
            console.log(this.a);
            console.log(this.b);
        }
    };
    
    let f = obj.func;
    f();
    ```
    
    Output :
    
    ```Plain
    Window{...}   // 'undefine in strict mode'
    undefined
    undefined
    ```
    

### call(), apply(), and bind() method :

- These methods are use to manually bind the value of 'this' to another value, for function.
- Syntax :
    
    ```Plain
    functionName.call(thisArg, arg1, agr2, ...)
    // binds and call immediatly, it returns the value that retrun by function.
    
    functionName.apply(thisArg, [argumentsArr])
    // bind and call immediatly, accept argument array, similar to call()
    
    functionName.bind(thisArg, arg1, arg2, ...);
    // only binds, returns new bounded funcion.
    ```
    
    Example :
    
    ```Plain
    let p1 = {
        Name : 'viral'
    }
    let p2 = {
        Name : 'harry'
    }
    let p3 = {
        Name : 'Elon'
    }
    
    function func(a=13, b=17 ){
        console.log(`${this.Name} : ${a} : ${b}`);
    }
    
    func.call(p1);
    func.apply(p2,[25]);
    let x = func.bind(p3,10,15);
    x();            // no need to pass argument again.
    ```
    
    Output :
    
    ```Plain
    viral : 13 : 17
    harry : 25 : 17
    Elon : 10 : 15
    ```
    

Nested function :

- You may nest a function within another function.
- The nested (inner) function is private to its containing (outer) function.
- The inner function forms a closure: the inner function can use the arguments and variables of the outer function, while the outer function cannot use the arguments and variables of the inner function.
- Example :
    
    ```Plain
    function addSquares(a, b) {
      function square(x) {
        return x * x;
      }
      return square(a) + square(b);
    }
    a = addSquares(2, 3); // returns 13
    b = addSquares(3, 4); // returns 25
    c = addSquares(4, 5); // returns 41
    ```
    
- Since the inner function forms a closure, you can call the outer function and specify arguments for both the outer and inner function:
    
    Example :
    
    ```Plain
    function outside(x) {
      function inside(y) {
        return x + y;
      }
      return inside;
    }
    fn_inside = outside(3);
    // Think of it like: give me a function that adds 3 to whatever you give
    
    result = fn_inside(5);         // returns 8
    result1 = outside(3)(5);    // returns 8
    ```
    

Multiply-nested functions :

- Functions can be multiply-nested.
    
    For example :
    
    ```Plain
    A function (A) contains a function (B), which itself contains a function (C).
    Both functions B and C form closures here. So, B can access A, and C can access B.
    In addition, since C can access B which can access A, C can also access A.
    ```
    
- The reverse, however, is not true. A cannot access C, because A cannot access any argument or variable of B, which C is a variable of. Thus, C remains private to only B.
- Thus, the closures can contain multiple scopes; they recursively contain the scope of the functions containing it. This is called scope chaining.
- When two arguments or variables in the scopes of a closure have the same name, there is a name conflict. More nested scopes take precedence. So, the innermost scope takes the highest precedence,

- Functions are objects themselves, these objects have methods. One of these, the apply() method.

### The arguments object

- You can refer to a function's arguments within the function by using the arguments object.
    
    ```Plain
    arguments:
    An array-like object containing the arguments passed to the currently executing function.
    
    arguments.callee:
    The currently executing function.
    
    arguments.caller:
    The function that invoked the currently executing function.
    
    arguments.length:
    The number of arguments passed to the function.
    ```
    
    Example :
    
    ```Plain

      // expected output: 2
    
      console.log(arguments[2]);
      // expected output: 3
    }
    
    func1(1, 2, 3);
    ```

## Advanced :

### Scoping :

- Scoping in programming refers to the rules for determining where and how variables and other identifiers are accessible within a program. There are two main types of scoping: **lexical scoping and dynamic scoping**.

### Closure :

- Inner function has complete access to the variables and function declared in outer function, which is called closure.
- Function bundled together with the lexical environment (reference to its surrounding state) forms closure.
- JavaScript allows for the nesting of functions and the "inner function has full access to all the variables and functions defined inside the outer function" (and all other variables and functions that the outer function has access to)
- However, the outer function does not have access to the variables and functions defined inside the inner function. This provides a sort of encapsulation for the variables of the inner function.
    
    Example:
    
    ```Plain
    function add(a,b){
        function inner(c){
            return a+b+c;
        }
        return inner;
    }
    
    let x = add(5,10);
    let y = add(100,150)
    x(15)   //30
    y(50)    //300
    ```
    
- x and y are both closures. They share the same function body definition, but store different lexical environments. In x's lexical environment, a and b is 5 and 10, while in the lexical environment for y, a and b is 100 and 150.
- you can use a closure anywhere that you might, normally use an object with only a single method.

### lexical environment:

- "associated data of outer function" to inner function is called lexical environment.

### Closure Scope Chain:

- Every closure has three scopes :
    
    ```Plain
    Local Scope (Own scope)
    Outer Functions Scope
    Global Scope
    ```

### Higher order function:

- A higher order function is a function that takes a another 'function' as an argument, or returns a 'function'.
- Higher order function, in contrast to "first order functions", which don’t take a function as an argument or return a function as output.
- Examples :
    
    `map()` and `filter()`. Both method, takes a function as an argument. They're both higher order functions.
    
- Function that receives another function
    
    Example :
    

```Plain
const oneWord = function (str){
    return str.replace(/ /g, '').toLowerCase();
}

const upperFirstWord = function (str){
    const [first, ...other] = str.split(' ');
    return [first.toUpperCase(), ...other].join(' ');
}

const transform = function ( str, fn ){
    return fn(str);
}

transform('javaScript is the best!', upperFirstWord)    // JAVASCRIPT is the best!
transform('javaScript is the best!', oneWord)        // javascriptisthebest!
```

Function that returns new function

Example:

```Plain
function count(){
    let counter = 1;

    return function(){
        counter++;
    }
}
```

### Callback functions:

- A callback is a **function passed as an argument to another function** is called callback function
- Where callbacks really shine are in asynchronous functions, where one function has to wait for another function (like waiting for a file to load).
    
    Example :
    
    ```Plain
    // function
    function greet(name, callback) {
        console.log('Hi' + ' ' + name);
        callback();
    }
    
    // callback function
    function callMe() {
        console.log('I am callback function');
    }
    
    // passing function as an argument
    greet('Peter', callMe);
    
    output:
    Hi Peter
    I am callback function
    ```
