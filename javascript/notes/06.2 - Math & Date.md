## Math object

- The built-in Math object has properties and methods for mathematical constants and functions.
- Unlike many other global objects, Math is not a constructor. All properties and methods of Math are `static`.
- Math Object only works with the `Number type`. It doesn't work with BigInt.

## Date object :

- The Date object has a large number of methods for setting, getting, and manipulating dates. It does not have any properties.
- Create date object :
    
    ```JavaScript
    const dateObjectName = new Date([parameters]);
    ```
    
    - The parameters in the preceding syntax can be any of the following :
        - `Nothing`  
            creates today's date and time.  
            
        - `integer values for year, month, and day`  
            creates a new date object with a specified date and time.  
            
        - `integer values for year, month, day, hour, minute, and seconds`  
            creates a new date object with a specified date and time.  
            
        - `string in form "Month day, year hours:minutes:seconds"`  
            creates a new date object with a specified date and time.  
            

### Constructor :

```Plain
Date()
// When called as a function, returns a string representation of the current date and time. All arguments are ignored.

new Date()
// When called as a constructor, returns a new Date object.
```

### Static methods :

```Plain
Date.now()        // returns current time in millisecond
Date.parse()
Date.UTC()
```

## JavaScript Timing Events

The window object allows execution of code at specified time intervals.

The two key methods for timing events are:

```Plain
window.setTimeout(function, milliseconds, funcArg1, funcArg2...)
Executes a function (only one time), after waiting a specified amount of milliseconds.
```

```Plain
window.setInterval(function, milliseconds, funcArg1, funcArg2...)
Executes a function (repetedly), after waiting a specified amount of milliseconds.
```

setTimeout() and setIntrval() are asynchronous function.

```Plain
window.clearTimeout(timeoutVariable);
The clearTimeout() method stops the execution of the function specified in setTimeout().
```

```Plain
window.clearInterval(timerVariable);
The clearInterval() method stops the executions of the function specified in the setInterval() method.
```

Example :

```Plain
var myVar = setTimeout(function, milliseconds);
clearTimeout(myVar);
```

Example :

```Plain
let myVar = setInterval(function, milliseconds);
clearInterval(myVar);
```
