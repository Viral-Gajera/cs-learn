# Identifiers

- Identifiers are name used to identify the variable, function, objects, etc...
  
    Rules :
    
    - Identifier must start with letter (A to Z), underscore ( _ ) or dollar sign ( $ ), subsequent character can also be digits.
    - Identifiers is case sensitive.
    - Reserve keyword can not be used as identifiers.

# Data Type

The ecmaScript standerd defines `eight` data-types

seven data types are primitive:

1. Number
2. String
3. Boolean
4. Undefined
5. Null
6. BigInt
7. Symbol

and `object` which is non primitive data-type.

## 1) Numbers

- JavaScript has only one type of number.
- Number can be written with or without decimal.
- The JavaScript Number type is a double-precision 64-bit binary format IEEE 754

### Numeric literals

- JavaScript numeric literals include integer literals in different bases as well as floating-point literals in base-10.



**Integer literals**

- Integer and BigInt literals can be written in decimal (base 10), hexadecimal (base 16), octal (base 8) and binary (base 2).

|leading digit|meaning|
|---|---|
|without zero|decimal|
|0/0o/0O|octal|
|0x/0X|hexadecimal|
|0b/0B|binary|

Example :

```js
123                        // one-hundred twenty-three
123.0                      // same
123 === 123.0              // true
```



**Floating-point literals**

- A floating-point literal can have the following parts:
    1. An unsigned decimal integer
    2. A decimal point (".")
    3. A fraction (another decimal number)
    4. An exponent.(e/E/e-/E-)
- Extra large number of extra small number can be written with scintific notation.
- Example:

```Plain
123e5
125.78e-5
```

**NaN**

- NaN stands for `Not a Number`.
- NaN is a JavaScript reserved word indicating that a number is not a legal number.

## 2) String type

### String literals

- string is `sequence of charectors`.
- string are written with single or double quotes.

```js
'volvo xc60';
"viral"
```

- We can use quotes inside a string, as long as they dont match the quotes surrounding the string.

```js
"it's alright"
```

- The following `escape charactor` can be use with string.

```Plain
\b
\f
\n
\r
\t
\'
\"
\\
\uNNNN
```



**Multiline string**

- You can also escape line breaks by preceding them with backslash. The backslash and line break are both removed from the value of the string.

```js
var str = 'this string \\
is broken \\
across multiple \\
lines.'
console.log(str);     // this string is broken across multiple lines.
```

- You can call any of the String object's methods on a string literal value.
- A String object can always be converted to its primitive counterpart with the valueOf() method.



**Template literals**

- Template literals are enclosed by the `back-tick` character instead of double or single quotes.

```js
`string text ${expression} string text`
```

Example :

```js
var name = 'Bob', time = 'today';
console.log(`Hello ${name}, how are you ${time}?`);
```

**Comparing strings**

- In C, the strcmp() function is used for comparing strings. In JavaScript, you just use the less-than and greater-than operators:

```js
let a = 'a'
let b = 'b'
if (a < b) {         // true
  console.log(a + ' is less than ' + b)
} else if (a > b) {
  console.log(a + ' is greater than ' + b)
} else {
  console.log(a + ' and ' + b + ' are equal.')
}
```

Note that a == b compares the strings in a and b for being equal in the usual case-sensitive way.

## 3) Boolean

### Boolean literal

- A boolean is a logical data type that can have only the values `true` or `false`.
- Boolean conditionals are often used to decide which sections of code to execute ( such as in if statements ) or repeat (such as in for loops).



**Falsy value**

- A fasly value is a value that is considered false when encountered in a Boolean context.

```js
false
zero [0,-0,0n]
empty string ["", '', ``]
null
undefined
NaN
```

```js
{}, [], "false" --> true
```

### Boolean class

- The Boolean object is an object wrapper for a boolean value.
- The value passed as the first parameter is converted to a boolean value, if necessary.
- Any object of which the value is not undefined or null, including a Boolean object whose value is false, evaluates to `true` when passed to a conditional statement. For example, the condition in the following if statement evaluates to true :

```js
var x = new Boolean(false);
if (x) {
  // this code is executed
}
```

- Do not use a Boolean object to convert a non-boolean value to a boolean value. To perform this task, instead, use Boolean as a function, or a double NOT operator:

```js
var x = Boolean(expression);     // use this...
var x = !!(expression);          // ...or this

var x = new Boolean(expression); // don't use this!
```

- If you specify any object, including a Boolean object whose value is false, as the initial value of a Boolean object, the new Boolean object has a value of true.

```js
var myFalse = new Boolean(false);       // initial value of false
var g = Boolean(myFalse);               // initial value of true

console.log(myFalse);                     // prints Boolean {false}
console.log(g);                         // prints true
```

**Constructor**

```js

```

**Instance methods**


## 4) Undefined

- `undefined` is a primitive value automatically assigned to variables that have just been declared not no initialized.

```js
var x;									//create a variable but assign it no value
console.log("x's value is ", x)     	//logs "x's value is undefined"
```

- undefined is a property of the global object. That is, it is a variable in global scope. The initial value of undefined is the primitive value undefined.

## 5) Null

- The value `null` represents the intentional absence of any object value.
- It is one of JavaScript's primitive values.
- null is not property of the global object, like undefined can be. Instead, null expresses a lack of identification, indicating that a variable points to no object.

**Difference between null and undefined:**

- When checking for null or undefined, beware of the differences between equality (\==) and identity (\===) operators, as the former (\==) performs type-conversion.
  
    ```js
    typeof null              // "object" (not "null" for legacy reasons)
    typeof undefined         // "undefined"
    
    null === undefined       // false
    null  == undefined       // true
    null === null            // true
    null  == null            // true
    !null                    // true
    isNaN(1 + null)          // false
    isNaN(1 + undefined)     // true
    ```
    



## 6) BigInt

### BigInt Literals

- With BigInts, you can safely store and operate on large integers even beyond the safe integer limit for Numbers.
- A BigInt is created by appending `n` to the end of an integer or by calling the constructor.

Example :

```js
// BigInt

const x = BigInt(Number.MAX_SAFE_INTEGER);     // 9007199254740991n
x + 1n === x + 2n;                             // 9007199254740992n === 9007199254740993n
false

// Number
Number.MAX_SAFE_INTEGER + 1 === Number.MAX_SAFE_INTEGER + 2; // [ 9007199254740992 === 9007199254740992 ]
true

typeof 25n                  // bigint
typeof BigInt('10')      	// bigint
```

- A BigInt is not strictly equal to a Number, but it is loosely so.
- A BigInt value cannot be used with methods in the built-in Math object

### BigInt class

- BigInt is a primitive wrapper object used to represent and manipulate primitive bigint values, which are too large to be represented by the number primitive.

## 7) Symbol

### Symbol Literals

- In JavaScript, Symbol is a primitive value.
- symbol value is created by invoking the function `Symbol`, which dynamically produces an anonymous, unique value.
- A symbol may be used as an object property(key).

Example:

```js
// Here are two symbols with the same description:
let Sym1 = Symbol("Sym");
let Sym2 = Symbol("Sym");

console.log(Sym1 === Sym2)     // returns "false"
typeof Symbol('viral')         // symbol
```

- Symbols don't "Auto-Convert" to strings.

### Symbol class

- Symbol is a built-in object whose constructor returns a symbol primitive.
- Every `Symbol()` call is guaranteed to return a unique Symbol.
- The following syntax with the new operator will throw a TypeError:

```js
let sym = new Symbol()  // TypeError
```

- If you really want to create a Symbol wrapper object, you can use the Object() function:

```js
let symObj = Object(sym)
typeof symObj   // "object"
```
