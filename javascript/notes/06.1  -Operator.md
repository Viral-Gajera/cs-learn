## Arithmatic Operator :

- An arithmatic operatoer takes numerical value (either literals or variable) as their operands and return a single numerical value.
- Arithmatic operators are listed in following table.
    
    |   |   |
    |---|---|
    |Operator|Description|
    |+|Addition|
    |-|Subtraction|
    |*|Multiplication|
    |/|Division|
    |%|Modules|
    |**|Exponentiation|
    |++|Increment|
    |--|Decrement|
    

### Modulus Operator :

- The remainder operator (%) returns the remainder left over when one operand is divided by second operator.
- Syntax :
    
    ```Plain
    x % y
    ```
    
- Example :
    
    ```Plain
    // Remainder with positive dividend
    
    	13 % 5		// 3
    	1 % (-2)	// 1
    	1 % 2		// 1
    	2 % 3		// 2
    	5.5 % 2		// 1.5
    
    
    // Remainder with negative dividend
    
    	-13 % 5		// -3
    	-1 % 2		// -1
    	-4 % 2		// -0
    
    // Always return sign of first operand.
    
    // Remainer with NaN
    
    	NaN % 2		// NaN
    
    // Remainer with infinity
    
    	Infinity % 2			// NaN
    	Infinity % 0			// NaN
    	Infinity % Infinity		// NaN
    ```
    

### Increment :

- Unary operator.
- Adds one to its operand.
- If used as a prefix operand (++x), return the value of its operand after adding one.
- If used as a postfix operand (x++), return the value of its operand before adding one.

### Decrement :

- Unary operator.
- Subtract one to its operand.
- If used as a prefix operator (--x), return the value of its operand after subtracting one.
- If used as a postfix operator (x--), return the value of its operand before subtracting one.

### Exponentiation Operator :

- The exponentiation operator (**) raise the first operand to the power of the second operand.
- x**y produces the same result as `Math.pow(x,y)`, except it also accept BigInt as operands.

### Unary Plus (+) :

- The unary plus operator (+) precedes its operand and evaluates to its operand but atttempts to convert it into a number, if it isn't already.
- It can convert string representation of integer and float, as well as the non-string value like true, false and null (into number).
- Example :
    
    ```Plain
    // use with number
    
    	const x = 1;
    	const y = -1;
    	console.log(+x);	//  1
    	console.log(+y);	// -1
    
    // use with non-number (try to convert into number)
    
    	+true				// 1
    	+false				// 0
    	+null				// 0
    	+""					// 0
    	+"4"				// 4
    	+"Hello"			// NaN
    	+undefined			// NaN
    ```
    

### Unary negation (-) :

- The unary negation operator (-) preceds its operand and negate it.
- Example :
    
    ```Plain
    // Negation number
    
    	const x = 3;
    	const y = -x;
    
    // Negating non numbers	(try to convert into number)
    
    	-true				// -1
    	-false				// -0
    	-null				// -0
    	-""					// -0
    	-"4"				// -4
    	-"Hello"			// NaN
    	-undefined			// NaN
    ```
    

## Assignment Operator :

- An assignment operator assigns a value to its left operand based on the value of its right operand.
- The simple assignment operator is `equal (=)`, which assigns the value of its right operand to its left operand.
    
    That is `x=f(x)` is assignment expression that assigns the value of f(x) to x.
    
- Assignment operator return an assigned value to it.
- There are also ==compound assignment== operators.
    
    ```Plain
    x op= f(x)	// equivalent x = x op f(x)
    ```
    
- `op` can be any other operator like :
    
    ```Plain
    +	-	*	/	%	**
    <<	>>	>>>	&	^	|
    &&	||	??
    ```
    

### Destructuring assignment :

- Destructuring is a JavaScript expression that allows us to extract data from arrays, objects, maps and set them into new, distinct variables.

### 1. Array destructuring :

- Syntax :
    
    ```Plain
    let [variable1, variable2] = [element1, element2, ...];
    
    // equivalent
    // variable1 = element1
    // variable2 = element2
    ```
    
- Example :
    
    ```Plain
    // assignning to variable
    
    	let a,b,rest;
    	[a,b] = [10,20];
    
    // assignning to a variable with default value
    
    	let [a=1, b=2] = [10];
    	// a = 10
    	// b = 2
    
    // rest pattern
    
    	let [a,b,...rest] = [10,20,30,40,50];
    	// a = 10
    	// b = 20
    	// rest = [30,40,50]
    ```
    

### 2. Object destructuring :

- Syntax :
    
    ```Plain
    let {variable1, variable2} = {variable1: value, variable2:value,...};
    		^						^
    	// name should be same
    ```
    
- Assigning to existing variable names :
    
    ```Plain
    var employee = {		// Object we want to destructure
        firstname: 'Jon',
        lastname: 'Snow',
        BirthDate: '1990'
    };
    
    var { firstname, lastname, BirthDate } = employee;
    ```
    
- Assigning to new variable names :
    
    ```Plain
    var { firstname: fn, lastname: ln, dateofbirth: dob } = employee;
    ```
    
- Assigning to a variable with default values :
    
    ```Plain
    var {
    	firstname = 'default firstname',
    	lastname = 'default lastname',
    	country = 'default country' } = employee;
    ```
    
- Assigning to new variable names with default values :
    
    ```Plain
    var {
    	firstname:fn = 'default firstname',
    	lastname:ln = 'default lastname',
    	country:ct = 'default country' } = employee;
    ```
    
- Rest pattern :
    
    ```Plain
    let a,b,rest;
    ( {a,b, ...rest} = {a:10, b:20, c:30, d:40} );
    
    a : 10
    b : 20
    rest : {c: 30, d: 40}
    ```
    

### Spread operator :

- The spread operator ... is used to expand or spread an "iterable".
- Syntax :
    
    ```Plain
    ...[a, b, c] --> a b c
    
       rest = [a,b,c]
    ...rest = a, b, c
    ```
    
- Example :
    
    ```Plain
    const arrValue = ['My', 'name', 'is', 'Jack'];
    
    console.log(arrValue);		// ["My", "name", "is", "Jack"]
    console.log(...arrValue);	// My name is Jack
    ```
    
- Copy Array Using Spread Operator :
    
    ```Plain
    const arr1 = ['one', 'two'];
    const arr2 = [...arr1, 'three', 'four', 'five'];
    ```
    
- Clone Array Using Spread Operator :
    - In JavaScript, objects are assigned by reference and not by values. For example,
        
        ```Plain
        let arr1 = [ 1, 2, 3];
        let arr2 = arr1;
        ```
        
    - Here, both variables `arr1` and `arr2` are referring to the `same array`. Hence the change in one variable results in the change in both variables.
    - if you want to copy arrays so that they do not refer to the same array, you can use the spread operator.
        
        ```Plain
        let arr1 = [ 1, 2, 3];
        let arr2 = [...arr1];
        
        console.log(arr1); // [1, 2, 3]
        console.log(arr2); // [1, 2, 3]
        
        // append an item to the array
        arr1.push(4);
        
        console.log(arr1); // [1, 2, 3, 4]
        console.log(arr2); // [1, 2, 3]
        ```
        
- Spread Operator with Object :
    - You can also use the spread operator with object literals. For example,
        
        ```Plain
        const obj1 = { x : 1, y : 2 };
        const obj2 = { z : 3 };
        
        const obj3 = {...obj1, ...obj2};
        console.log(obj3);		// {x: 1, y: 2, z: 3}
        ```
        

### Rest Parameter :

- When the spread operator is used as a parameter, it is known as the rest parameter.
- You can also accept multiple arguments in a function call using the rest parameter. For example,
    
    ```Plain
    let func = function(...args) {
        console.log(args);
    }
    
    func(3); 		// [3]
    func(4, 5, 6); 	// [4, 5, 6]
    ```
    
- You can also pass multiple arguments to a function using the spread operator. For example,
    
    ```Plain
    function sum(x, y ,z) {
        console.log(x + y + z);
    }
    
    const num1 = [1, 3, 4, 5];
    
    sum(...num1); 	// 8
    ```
    

## Comparison Operator :

- A comparison operator compares its operands and return a boolean value based on whether the comparison is true or not.
- The following table describe the comparison operator.
    
    |   |   |
    |---|---|
    |Operator|Description|
    |==|retuen true, if the operand are equal.|
    |!=|return true, if the operands are not equal.|
    |===|return true if the operands are equal and of the same type.|
    |!==|return true if the operands are of the same type but not equal, or are of different type.|
    |>|return true if the left operand is greater than right operand.|
    |>=|return true if the left operand is greater than or equals to right operand.|
    |<|return true if the left operand is less than the right operand.|
    |<=|return true if the left operand is less than or equals to right operand.|
    

## Logical Operator :

- Logical operator are typically used with boolean value, when they are, they returns a boolean value.
- However `&&` and `||` operator actually return the value of one of the specified operands, so if these operators are used with non boolean value, they may return a non-boolean value.
- The logical operator are describe in the following table.
    
    |   |   |
    |---|---|
    |Operator|Description|
    |expr1 && expr2|Return expr1 if it can be converted to false, otherwise returns expr2.|
    |expr1 \| expr2|Return expr1 if it can be converted to true, otherwise return expr2.|
    |!expr|Return false if its single operand that can be converted to true, otherwise return true.|
    

### Nullish Coalesing Operator :

- Nullish coalesing operator `(??)` that works like || but it only return the second expression, when the first one is `nullsh` (null or undefined).

## Bitwise Operator :

- A bitwise operator treats their operands as a set of 32 bits (zero and one) rather than as decimal, hexadecimal or octal numner.
- The following table summaarizes javascript's bitwise operators.
    
    |   |   |
    |---|---|
    |Operator|Description|
    |a & b|return a one in each bit position for which the corresponding bit of both operands are ones.|
    |a \| b|return a zero in each bit position for which the corresponding bit of both operand are zero.|
    |a ^ b|return a zero in each bit position for which the corresponding bit of both operand are same.|
    |~a|Inverts the bits of its operand|
    |a << b|shift 'a' in binary representation 'b' bits to left, shifting in zero from the right.|
    |a >> b|shift 'a' in binary representation 'b' bits to right, discarding bits shifted off.|
    |a >>> b|shift 'a' in binary representation 'b' bits to right, shifting in zero from the left.|

## Comma Operator :

- The comma operator `(,)` evaluates both of its operands and returns the value of the last operand.
- Example :
    
    ```Plain
    let x = (5,3)	// x = 3
    ```
    
- This comma operator is primarily used inside a for loop, to allows multiple variable to updated each time through the loop.
- Example :
    
    ```Plain
    for(var i=0, j=10; i<=j; i++, j--){}
    ```
    

## Grouping operator ():

- The grouping operator ( ) controls the precedence of evaluation in expressions.
    
    ```Plain
    console.log(1 + 2 * 3);		// 1 + 6
    // expected output: 7
    
    console.log((1 + 2) * 3); 	// 3 * 3
    // expected output: 9
    ```

## Relational Operator

- A relational operator compares its operands and returns a boolean value based on whether the comparison it true.

- Syntax :
    
    ```Plain

    ```
    
- Where propName or Number is string, numeric or symbol expression representing a property name of array index and objectName is the name of an object.

### instanceof

- Syntax :
    
    ```Plain

    ```
    
- Where objectName is the name of object to compare to objectType and objectType is an object type such as date or array.

## Other Operator

### new

- The `new` operator lets developers create an instance of a user-defined object type or of one of the built-in object types that has a constructor function.
- Example :
    
    ```Plain
    function Car(make, model, year) {
    	this.make = make;
    	this.model = model;
    	this.year = year;
    }
    
    const car1 = new Car('Eagle', 'Talon TSi', 1993);
    console.log(car1.make);
    // expected output: "Eagle"
    ```
    

### Optional chaining (?.)

- The optional chaining `?.` is a safe way to access nested object properties, even if an intermediate property doesn’t exist.
- Syntax :
    
    ```Plain
    obj.val?.prop
    obj.val?.[expr]
    obj.arr?.[index]
    obj.func?.(args)
    ```
    
- Example :
    
    ```Plain
    let obj = {
        prop1 : 'value1',
        prop2 : { NestProp1:'NestValue1' }
    }
    
    obj.prop1   			// 'value1'
    obj.prop2   			// {NestProp:'NestValue1'}
    obj.prop2.NestProp1		// 'NestValue1'
    obj.prop2.NestProp2  	// undefine
    obj.prop3				// undefine
    obj.prop3.NestProp1		// Error
    obj.prop3?.NestProp1	// undefine
    ```

## Type conversion and Type coercion :

### (i) Type conversion :

- Type conversion means transfer of data from one data type to another.
- Programmer manually have to do type conversion.

### To String Conversion :

- In this conversion, the any other data type is converted to a string when we need it.
    1. String(ValueToConvert);

    4. number.toFixed(digits);
    5. number.toPrecision(precision);

    1. Number(valueToConvert)

### (ii) Type coercion :

- Type coercion is similar to type conversion, but the only key difference is the coercion performed automatically or implicitly by the JavaScript engine.

### To String Coercion :

- When a string is added with the number or non-string value using the plus(+) operator then the output of the expression is always a string.
- Example :
    
    ```Plain
    '1' + 2					// 12
     2 + 2 +'1' + true		// 41true
    '12' + undefined		// 12undefined
    '12' + null				// 12null
    '12' + NaN				// 12null
    ```
    

### To Number Coercion :

- The mathematical operations like Subtraction`(-)`, Multiplication`(*)`, Division`(/)`, and Modulus`(%)` performed with the string then the output of the expression is converted into a number implicitly.
- In number coercion, the plus`(+)` operator is `not` used.
- Example :
    
    ```Plain
    '12' - 2			// 10
    '2' * 2				// 4
    '10' / 2			// 5
    '10' % 2			// 0
    'Hello' - 'World'	// NaN
    'Hello' * 2			// NaN
    ```
    

### To Boolean Coercion :

- In boolean coercion, the boolean values such as true and false are converted to a number.
- Example :
    
    ```Plain
    true + 1			// 2
    false - 1 			// -1
    true * undefined	// NaN
    false / null		// NaN
    true % NaN			// NaN
    ```
