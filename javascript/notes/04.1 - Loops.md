## Loops and iteration:

- Loops offer a quick and easy way to do something repeatedly.
- The statements for loops provided in JavaScript are :
    
    ```Plain
    for statement
    do...while statement
    while statement
    
    labeled statement
    
    break statement
    continue statement
    
    for...in statement
    for...of statement
    ```
    

### for statement :

- A for loop repeats until a specified condition evaluates to false.
- Syntax :
    
    ```Plain
    for [initialization]; [conditionExpression]; [increment])
    {
        //statement;
    }
    ```
    

### do...while statement :

- The do...while statement repeats until a specified condition evaluates to false.
- Syntax :
    
    ```Plain
    do{
      statement
    }while (condition);
    ```
    
- statement is always executed once before the condition is checked.

### while statement :

- A while statement executes its statements as long as a specified condition evaluates to true.
- Syntax :
    
    ```Plain
    while (condition)
    {
        statement
    }
    ```
    

### labeled statement :

- you can use a label to identify a loop, and then use the break or continue statements to indicate whether a program should interrupt the loop or continue its execution.
- Syntax :
    
    ```Plain
    label :
       statement
    ```
    
- The value of label may be any JavaScript identifier that is not a reserved word. The statement that you identify with a label may be any statement.

### break statement :

- the break statement used to terminate the loop.
- Syntax :
    
    ```Plain
    break;                // terminals inner most loop
    break [label];        // terminates the specified enclosing labeled statement.
    ```
    

### continue statement :

- continue statement used to skip specified iteration.
- The continue statement can be used to restart a while, do-while, for, or label statement.
- Syntax :
    
    ```Plain
    continue;
    continue [label];
    ```
    

### for...in statement :

- The `for...in` loop is designed to loop over the property `key of an object`.
- Syntax :
    
    ```Plain
    for (variable in object)
    {
      statement
    }
    ```
    
- with Object :
    
    ```Plain
    let obj = {
        firstName : 'viral',
        lasrName : 'gajera',
        age : 19,
        car : 'bugatti'
    };
    
    for( let x in obj ){
        console.log(x);
    }
    
    output:
        firstName
        lasrName
        age
        car
    ```
    
- with Array :
    
    ```Plain
    let arr = [ 'viral', 'gajera', 18, 'bugatti' ];
    
    for( let i in arr ){
        console.log(i);
    }
    
    output:
        0
        1
        2
        3
    ```
    

### for...of statement :

- The `for...of` loop used to Iterate over `iterable objects` (including Array, Map, Set, arguments object and so on), invoking a custom iteration hook with statements to be executed for the "value of each distinct property".
- with Object :
    
    ```Plain
    let obj = {
        firstName : 'viral',
        lasrName : 'gajera',
        age : 19,
        car : 'bugatti'
    };
    
    for( let x of obj ){
        console.log(x);
    }
    
    output:
        TypeError: obj is not iterable
    ```
    
- with Array :
    
    ```Plain
    let arr = [ 'viral', 'gajera', 18, 'bugatti' ];
    
    for( let i of arr ){
        console.log(i);
    }
    
    output:
        viral
        gajera
        18
        bugatti
    ```
