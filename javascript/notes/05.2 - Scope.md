## Scope:

- scope determines when and where the varible/constants are considered to be defined.
- Scope determines the accessibility (visibility) of variables.
- Scope refers to the availability of variables/functions in certain parts of the code.
- JavaScript has 3 types of scope:
    - Block scope
    - Function scope
    - Global scope (anything declared in global scope will available to all scope in program)

### Scope of variable:

- Region in which certain variable is accessible.

### Static and dynamic scoping:

- scoping:
    
    scoping is necessary if you want to reuse variable names:
    
- Example :
    
    ```Plain
    int func1()
    {
        int a = 10;
    }
    int func2()
    {
        int a = 40;
    }
    ```
    

### Static scoping:

- In static scoping (lexical scoping), definition of a variable is resolved by searching its containing block or function. if taht fails then searching the outer containing block and so on.
- Example :
    
    ```Plain
    let  a = 10;
    
    function func1(){
        let a = 15;
        func2();
    }
    
    function func2(){
        console.log(a);
    }
    
    func1();    // 10
    ```
    

### Dynamic scoping:

- In dynamic scoping, definition of a variable is resolved by searching its containg block and if not found, then searching its calling function and it still not found then the function which called that calling fucntion will be searched and so on.
- Example :
    
    ```Plain
    let  a = 10;
    
    function func1(){
        let a = 15;
        func2();
    }
    
    function func2(){
        console.log(a);
    }
    
    func1();    // 15
    ```
    

### Scope chain:

- Whenever our program tries to access a variable, it first, start the searching from local scope, if the variable is not found, it'll continue searching in its outer scope (or parent functions' scope) until it reaches the global scope. which is called scope chain.
