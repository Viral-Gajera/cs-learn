# Literals

- Literals are constant value which can be assign to variable.
- Javascript has the following type of literals
    - Numerical literals
    - Boolean literals
    - String literals
    - RegExp literals
    - Object literals
    - Array literals

# RegExp literals

- A regex literal is a pattern enclosed between slashes.
- Syntax:

```js
/pattern/modifiers;
```

- Example :

```js
var re = /ab+c/;
typeof /ab+c/        //object
```

- Regular expressions are patterns used to match character combinations in strings. In JavaScript, regular expressions are also objects.
- These patterns are used with the exec() and test() methods of RegExp, and with the `match()`, `matchAll()` etc... methods of String.

|Return type|Method|
|---|---|
|Array \| null|match(RegExp)|
|RegExpStringIterator|matchAll(RegExp)|
|string|replace(old, new)|
|string|replaceAll(old, new)|
|index \| -1|search(RegExp)|
|Array|split(separator, [limit])|

## Creating a regular expression :

- You construct a regular expression in one of two ways :
- Using a regular expression literal, which consists of a pattern enclosed between slashes, as follows:

```js
const re = /ab+c/;
```

- Or calling the constructor function of the RegExp object, as follows:

```js
const re = new RegExp('ab+c');
```

## Character classes :

- Character classes distinguish kinds of characters such as, for example, distinguishing between letters and digits.

|Character|Meaning|
|---|---|
|.|any character except line terminators [\n, \r, \u2028 or \u2029]|
|\w \d \s|word, digit, whitespace|
|\W \D \S|not word, not digit, not whitespace|
|\\. \\* \\\|escaped special characters|
|\t \n \r|tab, linefeed, carriage return|
|\v \f \0|vertical tab, form-feed, null character.|
|[\b]|matches a backspace.|
|\\|Indicates that the following character should be treated specially, or "escaped"|

## Assertions:

- Assertions include boundaries, which indicate the beginnings and endings of lines and words, and other patterns indicating in some way that a match is possible.

|Character|Meaning|
|---|---|
|^|Matches the beginning of input. If the multiline flag is set to true, also matches immediately after a line break character. Ex. /^A/|
|$|Matches the end of input. If the multiline flag is set to true, also matches immediately before a line break character. Ex. /t$/|
|\b|Matches a word boundary.|
|\B|Matches a non-word boundary.|
|(?<=y)x|Positive Lookbehind assertion ("x" only if "x" is preceded by "y").|
|(?<!y)x|Negative lookbehind assertion (Matches "x" only if "x" is not preceded by "y")|
|x(noty)|Positive Lookahead assertion (Matches "x" only if "x" is followed by "y")|
|x(?!y)|Negative lookahead assertion (Matches "x" only if "x" is not followed by "y".)|

  

## Groups and ranges :

- Groups and ranges indicate groups and ranges of expression characters.

|Character|Meaning|
|---|---|
|x \| y|Matches either "x" or "y"|
|[abc]|Any of a, b, or c|
|[^abc]|Not a, b, or c|
|[a-g]|One character between a & g|
|(x)|Capturing group|
|(?\<Name>x)|Named capturing group|
|(?:x)|Non-capturing group|

## Quantifiers :

- Quantifiers indicate numbers of characters or expressions to match.

|   |   |
|---|---|
|Character|Meaning|
|x+|Should repeat at least one time|
|x*|Should repeat zero or more times|
|x?|Used for optional things (zero or one time)|
|x{n}|Where "n" is a positive integer, matches exactly "n" occurrences of the preceding item "x".|
|x{n,}|Where "n" is a positive integer, matches at least "n" occurrences of the preceding item "x".|
|x{n,m}|Where "n" is 0 or a positive integer, "m" is a positive integer, and m > n, matches at least "n" and at most "m" occurrences of the preceding item "x".|

## Advanced searching with flags :

|Flag|Meaning|
|---|---|

# Object literals

- An object literal is a list of zero or more pairs of `property : values`, separated by comma.
- Objects are written with curly braces { }.
- Example :

```js
let person = {
    firstName : 'john',
    lastName : 'cena'
};
```

- Property of object can be accessed using dot `.`
- Ex. `person.firstName`
- You can use a numeric or string literal for the name of a property. 
- You can also nest an object inside another. The following example uses these options.
- Example :

```js
var car = {
    manyCars: { a: 'Saab', b: 'Jeep'},
    7: 'Mazda',
    'prop': func(){...}
};

console.log(car.manyCars.b);     // Jeep
console.log(car[7]);             // Mazda
console.log(car.prop);             //retuened value from function.
console.log(car['prop']);         //retuened value from function.
```

- If the property name would not be a valid JavaScript identifier or number, it must be enclosed in `quotes`.
- Property names that are not valid identifiers cannot be accessed as a dot (.) property, but can be accessed and set with the array-like notation("[]").

## Enhanced Object literals:

- Object literals are <u>extended</u> to support setting the prototype at construction, shorthand for `foo: foo` assignments, defining methods, making super calls, and computing property names with expressions.
- Example :

```js
let handler = 45;
let theProtoObj = Object.prototype

var obj = {
    // __proto__
    __proto__: theProtoObj,

    // Shorthand for 'handler: handler'
    handler,    //handler : 45

    // Methods
    toString() {
     // Super calls
     return 'd ' + super.toString();
    },

    // Computed (dynamic) property names
    [ 'prop_' + (() => 42)() ]: 42 // prop_42 : 42

};
```

# Array literals

- An array is an orderd list of value that you refer to with name and an index.

## Creating an array :

```js
let arr = new Array(E1, E2, ...EN);
let arr = Array(E1, E2, ...EN);
let arr = [E1, E2, ...EN];     (array literal)
```

- Array element can be any primitive value or object, function etc...

## Array Length :

- To create an array with non zero length, but without any items, either of the following can be used.
- Example :

```js
let arr = new Array(arrayLengh);

let arr = Array(arrayLengh);

let arr = [];
arr.length = arrayLength;
```

- In above code, arrayLenght must be Number, otherwise an array with a single element will be created.
- If you wise to initialize an array with a single element and the element happens to be number. you must use the bracket syntax.

## Referring to array element :

- You can refer to the first element of array as `arr[0]`, the second element of array as `arr[1]` and so on,...
- The index of the element begin with `zero`.
- Example:

```js
let arr = ['one', 'two', 'three'];

arr[2];                // three
arr['length'];         // 3 [ returns length of array ]
```

## Multi-dimensional array :

- Array can be nested, meaning that an array can contain another array as an element using this characteristic of javascript array, multi-dimensional array.
- Example:

```js
let arr = [ [1,2,3], [4,5,6], [7,8,9] ];

arr[0][1]    // 2
arr[1][2]    // 6
arr[2][0]    // 7
    ^  ^
    |  |
  row column
```
