# Introduction to javascript

- Javascript is high-level, prototype-based object oriented, multi-paradigm, dynamic, single threated, garbage-collected programming language with first-class function and non-blocking event loop concurrency model.
- Javascript was invented by brendan eich in 1995 and become ECMA standard in 1997.
- ECMA script is the office name of the language.

# Javascript code placement

## The \<script> tag :

- In HTML, javascript code is inserted between `<script>...</script>` tag.
- Example

```HTML
<script>
    let x = 13;
    console.log(x);
</script>
```

- **Javascript in** `<head>` **or** `<body>`
    - Script can be placed in `<body>` or in the `<head>` section of HTML page, or in both.
    - Placing script at bottom of `<body>` element, improves the display speed.
    - We can place any number of `<script>` tag in HTML document.

## External javascript

- Script can also be place in external File.
- Javascript file have the file extension `.js`
- To use an external script, put the path of script file in `src` ( source ) attribute of `<script>` tag.
- Example

```HTML
<script src="myScript.js" ></script>
```

- you can place an external script refernce in `<head>` or `<body>` as you like.
- External script can not contain `<script>` tag

# Javascript output

- Javascript can display data in different ways.
    1. Writing into HTML element using `innerHTML`.
    2. Writing into HTML output using `document.write()`.
    3. Writing into an alert an alert box, using `window.alert()`.
    4. Writing into the browser console, using `console.log()`.

## 1. innerHTML

- The innerHTML property define the HTML content.
- To access a HTML element, javascript can use `document.getElemenetByID('id')` method.
- Example :

```HTML
<p id='demo'></p>

<script>
    document.getElementById('demo').innerHTML = 'This is a string';
</script>
```

## 2. document.write()

- For testing purpose it is convenient to use document.write().
- Using document.write() after an HTML document is loaded, will delete all existing HTML.
- Example :

```HTML
<script>
    document.write('hello javascript');
</script>
```

## 3. window.alert()

- You can use alert box to display data.
- You can skip the window keyword.
- In javascript, the window object is global scope object that means that variable, property and method by default belongs to the window object.
- This also means that specifiying the window keyword is optional.

Example :

```HTML
<script>
    window.alert('my name is viral');
    alert('this is without window keyword');    // returns 'undefine'
</script>
```

- Note :

    `window.confirm('string')`;

    - To verify or accept something
    - 'ok' : true , 'cancel' : false

    `window.prompt('text', 'default text')`;

    - user input
    - 'ok' : input-string , 'cancel' ; null

## 4. console.log()

- For debugging purpose, we can call the `console.log()` method in the browser to display data.
- Example :

```HTML
<script>
    console.log('hello world);
</script>
```

# Statements

- A computer program is list of instruction for computer and these instructions are called statement.
- Statement are composed of tokens (reserve keyword, identifiers, operators, literals, and special symbol).
- Example :

```js
let x = 10 + 5;

let x, y, z;
x = 5; y = 6;		// multiple statement
z = x + y;    
```

- When statement are seperated by semi colon, multiple statement on one line allowed.

## Expression

- An expression is combination of value, variables and operators, which computes to a value.
- The computation is called 'evaluation'.
- Example :

```js
x * 5 + 10
```

## Semicolon

- Semicolon used to separate multiple statement.
- When statement are separated by semicolon, multiple statement on one line allowed.

## White space

- javascript ignore multiple space.
- you can add white space to make code more readable.
- Example :

```js
let x = y + z;
```

## Keyword

- Keywords are reserved words in program, which has special meaning to compiler (or interpreter).
- It can not be used as a name of identifiers.
- Example :

| keywords | keywords | keywords |
|---|---|---|
|abstract|argument|await|
|byte|catch|class|
|default|enum|eval|
|export|imports|interface|
|native|package|yield|
|with|volatile|var|

## Comments

- Comment are used to explain the code and make it (code) more readable.
- Comments are ignored by compiler/interpreters.
    - Single line comment : `//`
    - Multiline comment : `/* */`
