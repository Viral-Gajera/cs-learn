# Introduction

- React is a JavaScript library for building user interfaces.
- React is used to build single-page applications. React allows us to create reusable UI components.

# Create React App :

```Shell
# CRA
npx create-react-app app-name
npx create-react-app app-name --template cra-template-pwa

# Vite
npm create vite app-name
npm i

npm create vite app-name --template react
npm i
```

# Run the React Application :

```Plain
cd appName

# CRA
npm start
npm run start

# Vite
npm run dev
```

- `npm start` will execute `start` script, which is `react-scripts start` script.
- To run particular script from `package.json`, execute following command to terminal `npm run <script-name>`.
