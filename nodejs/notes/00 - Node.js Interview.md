Q. what is the difference between put and patch request.

- PUT is best used when we are updating or replacing entire existing data on the server.
- PATCH allows the modification of particular portions of a resource. It can be applied to change only particular portions of an entity data.
- Example:
  
    Let's consider a hypothetical SQL table called `users` with columns `id`, `name`, `email`, and `age`.
    
    ```Java
    PUT		-> Using PUT to update the entire user resource.
    PATCH	-> Using PATCH to partially update specific fields of the user. (i.e. age or name or ...)
    ```
